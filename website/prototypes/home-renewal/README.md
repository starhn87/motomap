# 홈페이지 리뉴얼: 첫 화면·발견 시안

- 2026-10-13 제안과 사용자 승인에 따른 로컬 시안. **운영 홈페이지에는 미적용**.
- `website/public`, Worker, 공유 URL·AASA·법률 문서·운영 상태는 변경하지 않는다.
- 기존 고해상도 라이딩 사진, 앱 아이콘, Apple 배지, 실제 지도·AI 캡처를 재사용한다.
  지도·AI 캡처는 현재 홈페이지의 자산이며 최종 반영 전에 최신 UI로 갱신할지 확인한다.
- 첫 화면은 짧은 등장 효과와 스크롤에 따른 최대 3.5% 확대만 사용한다.
  발견은 단색 배경, 중앙의 큰 앱 화면, 아래의 짧은 문구로 구분한다.
- 화면 전환은 두 실제 캡처 사이의 미리보기이며 API·인증·위치·분석 호출이 없다.
- 자연 스크롤을 유지하고 휠·터치·키보드 스크롤을 막지 않는다. 모션 감소 설정을 따른다.

## 미리보기

저장소 루트에서:

```bash
node website/prototypes/home-renewal/server.mjs
```

`http://127.0.0.1:4318/`로 연다. loopback에만 바인딩하고 파일 허용 목록으로 공개 자산만
제공한다. 새 패키지·공개 배포·원격 서비스 설정은 필요 없다. 확인 후 Ctrl+C로 종료한다.

서버 없이 다시 보는 단일 HTML은 다음 명령으로 생성한다.

```bash
node website/prototypes/home-renewal/export.mjs
```

출력 `/tmp/motomap-home-renewal/index.html`은 CSS·JS·공개 이미지를 포함하므로 브라우저에서
파일을 열어도 시안이 동작한다. 원격 연결은 사용자가 다운로드/현재 홈페이지 링크를 누를 때만 발생한다.

## 후속 경계

첫 화면과 발견만 완성한 디자인 시안이다. 길안내·내 바이크 섹션은 아직 구현하지 않았다.
디자인 승인 전 운영 HTML에 합치거나 기존 시네마틱 단계 동작을 제거하지 않는다.
최종 반영에는 최신 캡처·모바일 화면·모션·법률 링크·공유/운영 상태 보존을 확인한다.

## 2026-10-13 확인

- 브라우저 1440×900, 390×844, 320×700: 가로 넘침 없음, 제목 각 두 줄 유지.
- 실제 공개 이미지 모두 로딩, 지도/AI 화면 버튼 클릭·Enter 전환과 안내 문구 변경 확인.
- 자연 스크롤·섹션 이동·모바일 바이크 중심 크롭을 시각 확인했다.
- `npx tsc --noEmit`, 웹 테스트 5/5, 시안 JS/서버/내보내기 문법 검사 통과.
- 허용 페이지/자산 200, 비공개·경로 우회 요청 404, POST 405 확인.
- 단일 HTML 내 로컬 자산 참조 없음, 내장 JS 문법 검사 통과.
- OS 모션 감소 설정용 CSS·JS 분기는 포함하되 실제 OS 설정 전환 검증은 하지 않았다.
