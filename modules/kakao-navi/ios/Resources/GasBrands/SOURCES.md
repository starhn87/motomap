# 주유소 브랜드 이미지 원본

주유소 식별용으로 앱에 포함한다. 원본 비율·색상을 유지하고 흰 가격 말풍선 위에 맞춰 그린다.
실행 중 외부 이미지 서버를 호출하지 않는다. 확인일: 2026-10-27.

- GS칼텍스: https://www.gscaltex.com/images/common/svg/gscaltex_logo.png (공식 홈페이지)
- S-OIL: https://www.s-oil.com/images/common/logo.png (공식 홈페이지, CI: https://www.s-oil.com/company/CI.aspx)
- SK에너지: https://commons.wikimedia.org/wiki/File:SK_Energy_Logo.svg 의 250px PNG 원본 미리보기. 제조사 원본 출처가 명시된 로고이며 공식 CI와 대조했다: https://www.skenergy.com/company/ci
- HD현대오일뱅크: https://commons.wikimedia.org/wiki/File:HD_Hyundai_Oilbank_logo.svg 의 500px PNG 원본 미리보기. 제조사 원본 출처가 명시돼 있다.

알뜰은 `알뜰`, 자가상표/미지원 브랜드는 `주유` 텍스트로 표시한다. 다른 정유사의
로고를 대입하지 않는다. 알뜰 공식 BI 자료는 PDF 매뉴얼만 확인했으며 표지 이미지를
로고로 사용하지 않았다.
