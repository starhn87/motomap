# 홈페이지 디자인

## WEB-001 — 감성적인 첫 화면과 단정한 제품 소개를 분리하는 시안

- 날짜: 2026-10-13
- 상태: 대체됨(WEB-002 — 사용자 거절로 시안 롤백)
- 관련 구현: 시안 커밋 `cb7ade2`의 `website/prototypes/home-renewal/` (롤백됨)

### 배경

같은 라이딩 배경 위에 큰 앱 캡처와 제목을 계속 겹치는 구성에서 정보가 경쟁했다.
운영자는 깔끔하고 심플한 애니메이션 리뉴얼 제안에 동의하고 첫 화면·발견 섹션 시안을 요청했다.

### 시안의 결정

1. 첫 화면의 라이딩 사진과 바이크 중심 분위기는 유지하고 제목·설명·다운로드만 남긴다.
2. 발견은 차콜 배경으로 분리한다. 기존 선호처럼 데스크탑·모바일 모두 큰 실제 앱 화면을
   텍스트 위 중앙에 두고 지도/AI 캡처를 미리보기로 전환한다. 없는 기능·수치·후기를 만들지 않는다.
3. 짧은 등장·사진의 소폭 확대만 사용하고 모션 감소 설정과 JS 없는 콘텐츠 접근을 지원한다.
4. 시안은 자연 스크롤이다. 기존 홈페이지의 단계 잠금·제스처 처리 시행착오를 잊고 조용히
   대체하지 않는다. 운영에 합칠 때 변경 범위와 기존 스크롤 대체를 별도 확인한다.
5. 운영 public 디렉터리·Worker·약관·공유·AASA·상태 endpoint는 수정하지 않는다.
   시안은 loopback 전용 허용 목록 서버에서 확인하며 푸시·배포하지 않는다.

### 재검토 조건

시안 승인 뒤 길안내·내 바이크 소개로 확장하는 안이었으나 WEB-002로 중단했다.
실제 라이딩 영상은 촬영본이 생겼을 때 검토한다. 시안과 실서비스 구현을 같은 상태로 표시하지 않는다.

## WEB-002 — 첫 화면·발견 시안을 거절하고 롤백한다

- 날짜: 2026-10-14
- 상태: 활성
- 대체 대상: WEB-001 시안과 후속 확장

운영자가 시안을 확인한 뒤 "별로다. 롤백해."라고 요청했다. 구체적인 불만의 이유는
확인되지 않았으므로 색상·스크롤·구성 중 무엇이 문제였는지 추정해 기록하지 않는다.

`cb7ade2`에서 추가한 시안 코드·서버·내보내기 도구를 제거하고 결정 이력만 남긴다.
시안은 푸시·배포하지 않았으므로 운영 홈페이지와 앱은 변경할 필요가 없다.
별도 요청 없이 같은 시안을 다시 적용하거나 길안내·내 바이크 섹션으로 확장하지 않는다.
