# 공통 아이콘·터치 피드백

사용자가 누를 수 있는 요소를 즉시 알아차리고, 같은 행동을 화면마다 같은 시각 언어로
이해하도록 하는 앱 공통 상호작용 결정이다.

관련 구현:

- `app/course/[id].tsx`
- `components/map/PlaceBottomSheet.tsx`
- `components/map/TempPlaceSheet.tsx`
- `components/map/WeatherFab.tsx`
- `components/map/MapHome.tsx`

## 먼저 확인할 활성 원칙

1. 공유 행동은 `Ionicons`의 `share-outline` 아이콘으로 통일한다. 화면 성격에 따라 크기와
   색은 달라도 아이콘 모양은 바꾸지 않는다.
2. 사용자가 누르는 액션은 터치하는 동안 즉시 시각 피드백을 보여준다. `TouchableOpacity`의
   기본 투명도 변화도 유효한 피드백이며, `Pressable`은 눌림 스타일이나 애니메이션을 명시한다.
3. 지도 위 플로팅 버튼처럼 독립된 작은 컨트롤은 탭 아이콘과 같은 짧은 timing 축소 피드백을
   우선하되 손을 떼는 순간 원래 크기로 즉시 복귀한다. 카드·텍스트 버튼은 투명도 또는 테두리
   변화로 레이아웃을 움직이지 않게 한다.
4. 햅틱은 시각 피드백을 대체하지 않는다. 사용자가 햅틱을 꺼도 눌렀다는 사실을 알 수 있어야 한다.

## INTERACTION-001 — 공유 아이콘과 눌림 상태를 앱 공통 규칙으로 둔다

- 날짜: 2026-08-23
- 상태: 대체됨(INTERACTION-002)
- 관련 구현: `app/course/[id].tsx`, `app/my-rides.tsx`,
  `components/profile/RiderShareCard.tsx`, `components/map/`

### 배경

코스·주행기록은 `share-outline`을 사용했지만 장소 상세은 서로 다른 계열의 `share-2`를 사용해
같은 행동이 다른 기능처럼 보였다. 또한 `Pressable`에 눌림 상태가 없는 지도 날씨 버튼은 터치가
전달됐는지 시트가 열릴 때까지 알기 어려웠다.

### 결정

공유 액션은 모두 `Ionicons share-outline`으로 통일한다. 새 공유 진입점을 추가할 때도 같은
아이콘을 사용하고 접근성 라벨에 공유 대상을 명시한다.

일반 액션은 터치 중 투명도·색·테두리 중 하나 이상을 바꾸고, 지도 날씨 같은 플로팅 버튼은
탭 아이콘과 같은 timing 시퀀스(누르는 동안 82%, 뗀 뒤 한 번만 복귀)로 반응한다. 잔진동이
남는 물리 스프링은 쓰지 않는다. 이미 눌림 피드백을 제공하는
`TouchableOpacity`나 상태별 스타일이 있는 `Pressable`에는 중복 애니메이션을 얹지 않는다.
배경 닫기 영역이나 이벤트 전파만 막는 컨테이너처럼 독립 버튼으로 보이지 않는 요소는 예외다.

### 검토한 대안과 시행착오

모든 액션에 햅틱만 추가하면 햅틱을 끈 사용자와 기기에서 피드백이 사라지고, 모든 버튼에
스프링을 적용하면 손을 뗀 뒤에도 잔진동이 남아 반응이 늦게 끝난다. 컨트롤 형태에 맞춰 축소와 색상
피드백을 나누되, 반응이 있다는 원칙만 공통으로 유지한다.

### 영향과 재검토 조건

새로운 터치 액션을 만들 때 기본 피드백과 접근성 역할·라벨을 함께 확인한다. 시스템의 동작
줄이기 설정에서 timing 효과가 불편하거나 지도 조작 성능에 영향이 확인되면 플로팅 버튼도 투명도
피드백으로 낮춘다. 아이콘 라이브러리를 교체할 때는 공유 아이콘을 화면별로 다시 갈라놓지 않는다.

## INTERACTION-002 — 눌림 축소는 터치 중에만 유지한다

- 날짜: 2026-08-23
- 상태: 활성
- 관련 구현: `components/map/WeatherFab.tsx`

### 배경

터치를 뗀 뒤 106%까지 커졌다가 돌아오는 timing 시퀀스도 작은 플로팅 버튼에서는 눌림보다 후속
애니메이션이 더 강하게 느껴졌다. 사용자가 원하는 피드백은 터치 중 눌렸다는 표시이지 탭 완료 후의
별도 강조가 아니다.

### 결정

지도 날씨 버튼은 누르는 동안만 82%로 줄어들고, 손을 떼거나 터치가 취소되면 진행 중인 축소를
즉시 중단하고 100% 크기로 복귀한다. 오버슈트·스프링·복귀 timing 애니메이션은 사용하지 않는다.
공유 아이콘 통일과 일반 버튼의 투명도 피드백 원칙은 그대로 유지한다.

### 영향과 재검토 조건

새 플로팅 버튼도 터치 중 상태와 해제 상태를 명확히 분리한다. 시스템 동작 줄이기 여부와 관계없이
손을 뗀 뒤 애니메이션이 남지 않아야 한다.
