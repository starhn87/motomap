# 서비스 운영 중단과 재개

## OPS-001 — 위치기반서비스 관련 절차 정비 전까지 전체 서비스 중단

- 날짜: 2026-08-28
- 상태: 활성
- 관련 구현: `app/_layout.tsx`, `components/ServiceSuspendedScreen.tsx`, `website/src/index.js`

### 배경

모토맵은 지도 주변 검색과 경로 요청 과정에서 이용자의 위치를 사업자 시스템 또는 외부 API에
전송하고, 1.2.0부터는 앱 내 길안내도 제공한다. 위치기반서비스사업 신고 대상 여부와 필요한
운영 요건을 공식 상담으로 확정하고 사업자 등록 등 선행 절차를 정비할 때까지 추가 제공을
계속하지 않기로 했다.

운영 중단은 적용 이후의 제공을 멈추는 조치다. 이미 제공한 기간을 소급해 없애거나 법률 판단을
대체하지 않는다.

### 결정

전체 서비스 중단은 다음 경계를 모두 충족해야 완료로 본다.

1. App Store에서 앱을 판매 중단해 신규 다운로드를 막는다. 앱 레코드는 삭제하지 않는다.
2. OTA를 받을 수 있는 모든 출시 런타임에는 초기화 전 운영 중단 화면을 배포한다. 중단 화면은
   지도, 위치 구독, 길안내 SDK, 인증, 푸시, 분석을 시작하지 않는다.
3. OTA를 지원하지 않거나 아직 OTA를 적용하지 않은 설치본을 위해 백엔드를 중단하고, 클라이언트에
   내장된 지도·검색·길안내 공급자 자격 증명도 비활성화한다.
4. `motomap.kr`의 소개·공유 화면은 503 운영 중단 안내로 대체한다. 이용약관, 개인정보 처리방침,
   위치기반 서비스 이용약관과 계정·데이터 요청 이메일은 계속 접근 가능해야 한다.
5. 이용자 데이터는 삭제하지 않고 보존한다. 운영 중단 중 열람·삭제·처리정지 요청은
   `starhn87@gmail.com`으로 접수해 처리한다.

운영 재개에는 최소한 다음 확인이 필요하다.

- 사업자 등록과 실제 서비스 구조에 맞는 위치기반서비스사업 신고 또는 신고 비대상 확인
- 위치정보 이용약관·개인정보 처리방침·보호조치와 App Store 고지의 일치
- 공식 상담 또는 전문 검토 결과 기록
- 중단한 백엔드와 외부 공급자 자격 증명의 복구, 앱 런타임별 재개 OTA 검증
- 재개 버전의 보안·릴리스 호환성 검사와 사용자 공지

사업자 등록만 완료한 상태는 자동 재개 조건이 아니다.

구버전 중단 OTA를 발행할 때만 `MOTOMAP_EMERGENCY_RUNTIME_VERSION`을 대상 앱 버전으로 설정한다.
이 변수는 앱 버전과 `runtimeVersion: { policy: 'appVersion' }`을 함께 맞추는 비상 수단이며, 일반
빌드·OTA에서는 절대 설정하지 않는다. 대상 런타임과 발행 결과를 확인한 뒤 셸에서 해제한다.

### 검토한 대안과 시행착오

- App Store 판매 중단만으로는 기존 설치자와 구입 목록을 통한 재다운로드를 막지 못한다.
- 현재 런타임 하나에만 OTA를 발행하면 구버전 설치본이 계속 동작할 수 있다.
- Supabase만 중단하면 클라이언트 키로 직접 호출하는 지도·카카오 로컬·경로·길안내가 남는다.
- 원격 버전 정책은 해당 기능이 포함된 앱에서만 읽으므로 모든 출시본에 대한 중단 수단이 아니다.

따라서 스토어, 런타임별 앱, 백엔드, 외부 지도·길안내 공급자를 함께 중단한다.

### 영향과 재검토 조건

서비스 중단 또는 재개를 변경할 때는 이 문서를 가장 먼저 검토한다. 재개 시 이 항목을 삭제하지
않고 `대체됨`으로 표시한 뒤, 재개 조건과 실제 신고·검토 결과를 새 결정으로 연결한다.

운영 중단이 실제로 적용된 시각, 각 런타임 OTA 그룹, 백엔드·공급자·스토어 상태는 배포 기록에
남긴다. 비밀키나 계정 식별 정보는 문서에 기록하지 않는다.
