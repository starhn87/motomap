# App Store 등록 정보

## 앱 이름
모토맵 - 바이커 전용 지도

## 부제
바이커 장소, 코스, 이륜차 길안내

## 설명
바이커를 위한 지도 앱, 모토맵이에요.

일반 지도에서는 찾기 어려운 바이커 카페, 휴게소, 뷰포인트, 라이딩 코스를
한눈에 찾고, 이륜차 전용 길안내로 바로 출발할 수 있어요.

주요 기능

- 이륜차 전용 길안내: 자동차 전용도로를 피해서 안내해요. 추천, 시간, 거리, 큰길 네 가지 경로를 교통 상황 색으로 비교하고, 경유지는 드래그로 순서를 바꿔요. 주행 중에는 버튼 하나로 노면 위험을 제보하고, 지도의 주유소나 가게를 탭해 목적지를 바로 바꿀 수 있어요.
- 바이커 장소 탐색: 바이커 카페, 맛집, 휴게소, 정비소, 뷰포인트, 용품점, 캠핑장, 세차장을 카테고리로 찾아요.
- 실시간 유가: 화면에 보이는 주유소의 가격과 최저가가 지도에 떠요. 내 바이크를 등록하면 내 유종 가격이 먼저 보여요.
- 라이딩 날씨: 라이딩 점수와 시간대별 강수확률, 미세먼지에 폭염이나 호우 같은 기상특보까지 확인해요. 길안내를 시작할 때 경로에 비 소식이 있으면 미리 알려드려요.
- 라이딩 코스: 추천 코스를 골라 그대로 길안내를 받아요.
- 노면 위험 제보: 포트홀이나 모래 같은 위험을 제보하면 다른 라이더의 안내 화면에 경고로 떠요.
- 내 바이크: 기종 1,040종 자동완성과 제원 카드, 어디를 몇 번 다녀왔는지 라이딩 기록까지 이어져요.
- 장소 제보와 리뷰: 내가 아는 바이커 스팟을 공유하고, 리뷰와 즐겨찾기로 지도를 함께 채워가요.
- 간편한 계정 연결: Apple, 카카오, 네이버, Google 중 편한 방식으로 로그인하고 기존 계정에도 연결할 수 있어요.

라이더들이 직접 만들어가는 지도, 모토맵과 함께 달리세요.

- Apple·카카오·네이버·Google 로그인을 추가했어요. 기존 계정에도 다른 로그인 방식을 연결할 수 있어요.

- 검색 결과는 현재 지도 주변을 먼저 보여주고, 이어서 전국 결과를 보여줘요.
- 로그인과 키보드, 장소 상세 화면의 여러 오류를 고치고 안정성을 높였어요.
