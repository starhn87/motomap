# 위치정보 의무사항 기능 보완 — 로컬 검증 기록

날짜: 2026-10-11. LOC-001/OPS-010의 소스 검증 기록이다. 원격 적용 완료나 법적 적합성 인증이 아니다.

## 구현 범위

- OS 위치 권한과 별개로 위치 약관·연령 확인, 공급자별 전달 및 신규 방문 기록 저장 동의를 받는다.
- 설정에서 일시 중지·재시작·전체/방문 기록 철회, 본인 확인자료와 방문·완주 자료 열람·삭제,
  정정 문의를 제공한다. 철회 뒤 재동의 항목은 다시 미선택 상태에서 시작한다.
- 동의·공급자 범위·계정 변경을 GPS/외부 요청/길안내 진입과 완료 시점에 확인한다.
  중지 의도를 보안 저장소에 보관하고 서버·저장소 실패를 처리 성공으로 표시하지 않는다.
- 확인자료는 서버 시각·목적·공급자·요청 결과만 기록한다. 좌표·주소·검색어는 복제하지 않는다.
  6개월 보유 후 정리하고 철회 범위 자료는 기간 전이라도 삭제한다.
- 기존 자료를 소급 동의 또는 일괄 삭제하지 않는다. 리뷰·즐겨찾기는 유지하고 방문·완주는
  이용자가 명시적으로 철회·삭제한 범위만 삭제한다. 집·회사 통계 제외 자료도 열람한다.
- 네이티브 bridge 2에 위치 이용 차단·길안내 중지 계약을 추가한다. 미출시 1.2.8 후보의
  OTA 발행을 릴리스 검사에서 차단한다.

## 2026-10-12 화면 단순화·비파괴 저장 설정 보완

LOC-002에 따라 첫 동의를 한 화면으로 통합하고 공급자 부분 선택을 문서 ‘보기’로,
자료 열람·삭제·철회를 설정 안으로 배치했다. 기존 개인정보 보호 기능은 제거하지 않았다.
동일 계정의 약관 확인/토큰 갱신은 위치 상태를 재초기화하지 않는다. 일반 약관 수락 요청은
최초 JWT를 개별 헤더에 고정해 계정 전환 중 다른 계정 동의 저장을 방지한다.

사용자 승인 후 비파괴 저장 설정 함수의 실제 버전
`20261011150411_add_location_history_setting`을 적용했다. 신규 저장 OFF/ON은 기존 방문,
공급자, 상태, 동의 시각을 변경하지 않는다. 공개 invoker/private definer의 빈 search_path,
anon EXECUTE 거부와 authenticated 권한을 확인했다. 원격 롤백 fixture 24개를 통과했다.
이번 적용 직전/직후 리뷰 16·즐겨찾기 20·방문 41·기존 동의 38·동의 이력 39건 등 7개
테이블의 전체 행 체크섬이 동일했다. 앞선 38건과 이후 39건은 각각 해당 적용 시점의
기준값이며 기존 이력을 보정·삭제하지 않았다.

로컬 재검증: 타입 검사 exit 0, 앱 테스트 176/176, 웹 5/5, SQL fixture 38개,
릴리즈 일반/HEAD 기준·고지 준비·diff 검사 통과. OTA 검사는 미출시 native 후보를 의도대로
exit 1로 차단한다. 원격 Advisor의 기존 경고는 본 작업과 별개로 남아 있으며 전체 보안 문제가
해결됐다고 하지 않는다. 공급자 SDK 내부 GPS 프레임까지 관찰한 검증도 아니다.

최신 단순화 소스의 재빌드·실기기 동의와 스위치 동작 검증은 별도 후속 결과로 기록한다.
