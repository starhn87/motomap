# 위치정보 의무사항 기능 보완 — 로컬 검증 기록

날짜: 2026-10-11. LOC-001/OPS-010의 소스 검증 기록이다. 원격 적용 완료나 법적 적합성 인증이 아니다.

## 구현 범위

- OS 위치 권한과 별개로 위치 약관·연령 확인, 공급자별 전달 및 신규 방문 기록 저장 동의를 받는다.
- 설정에서 일시 중지·재시작·전체/방문 기록 철회, 본인 확인자료와 방문·완주 자료 열람·삭제,
  정정 문의를 제공한다. 철회 뒤 재동의 항목은 다시 미선택 상태에서 시작한다.
- 동의·공급자 범위·계정 변경을 GPS/외부 요청/길안내 진입과 완료 시점에 확인한다.
  중지 의도를 보안 저장소에 보관하고 서버·저장소 실패를 처리 성공으로 표시하지 않는다.
- 확인자료는 서버 시각·목적·공급자·요청 결과만 기록한다. 좌표·주소·검색어는 복제하지 않는다.
  6개월 보유 후 정리하고 철회 범위 자료는 기간 전이라도 삭제한다.
- 기존 자료를 소급 동의 또는 일괄 삭제하지 않는다. 리뷰·즐겨찾기는 유지하고 방문·완주는
  이용자가 명시적으로 철회·삭제한 범위만 삭제한다. 집·회사 통계 제외 자료도 열람한다.
- 네이티브 bridge 2에 위치 이용 차단·길안내 중지 계약을 추가한다. 미출시 1.2.8 후보의
  OTA 발행을 릴리스 검사에서 차단한다.

## 아직 실행하지 않은 단계

1. 승인 후 `20261011131542_add_location_privacy_controls.sql` 원격 적용 및 권한·기존 자료 보존 확인.
   두 세션에서 방문 INSERT와 철회 잠금, 만료 처리·스케줄을 검증한다. 기존 일시 중단 작업은 유지한다.
2. 새 네이티브 빌드에서 Swift importer·링크·서명 및 실기기 중지/철회를 확인한다.
   SDK GPS manager 식별, 늦은 콜백, 백그라운드 복귀, 앱 자체 위치 센서 오차단 여부를 포함한다.
3. 새 동의 화면·자료 관리·기존 기능을 실제 설치본에서 확인한 뒤 고지와 심사 정보를 동기화한다.
4. 푸시·웹 배포·OTA·심사 제출·판매 재개·전체 알림은 각 승인 범위를 확인한 뒤 실행한다.
