# 1.2.8 App Store 출시·판매 지역 복구 기록

## 승인 범위

운영자는 1.2.8 수동 출시, 판매 국가·지역 복구와 실제 다운로드·업데이트 가능 여부 확인을
승인했다. 후속 질문에서 **모든 175개 국가·지역**을 명시 선택했다. 전체 푸시는 보내지 않는다.
웹 소개·공유, 구버전 연결 OTA, 정지된 자동 작업 복구와 EU 거래자 자격 신고는 이번에 변경하지 않는다.

## 실제 App Store Connect 결과

- 2026-10-13 08:40 KST: 1.2.8(38)의 `개발자 출시 대기 중`과 판매 중단을 확인했다.
  `이 버전 출시`의 최종 확인 후 **배포 준비됨**으로 바뀌었다. 다른 빌드·평점·가격을 변경하지 않았다.
- 중단 기록의 `175개 모두 사용 불가`만으로 이전 판매 지역 목록을 확정할 수 없었다.
  처음 전체 선택한 초안은 저장 전에 취소했고, 운영자의 명시적인 175개 지역 선택 후 다시 진행했다.
- 09:08 KST: `앱이 175개의 국가 또는 지역에서 사용할 수 있게 됩니다` 확인 후 저장했다.
  전체 선택이 함께 켠 **향후 추가 국가·지역 자동 판매** 옵션은 원래 OFF로 돌려놓았다.
- 실제 결과는 대한민국을 포함한 **148개 지역: 사용 가능으로 전환 처리 중**이다.
  ASC의 노란색 상태 표시는 `처리 중에서 사용 가능`이며 이미 공개 완료됐다는 의미로 쓰지 않는다. EU **27개 지역:
  거래자 자격 여부가 제공되지 않음**이다. 175개 선택 저장과 전 지역 공개 완료는 구분한다.

EU 상태의 `보기`는 유럽 연합 App Store 배포에 거래자 자격 여부가 필요하다고 안내한다.
[Apple DSA 안내](https://developer.apple.com/help/app-store-connect/manage-compliance-information/manage-european-union-digital-services-act-trader-requirements)에
따르면 자격은 운영자가 평가해야 하며, 거래자 등록에는 공개 주소·전화·이메일 확인과 문서 검증이
포함된다. 별도 확인 없이 비거래자로 선언하거나 계정 수준 신고·법적 확인을 대신 제출하지 않는다.
EU 지역은 선택 상태로 남아 있으나 요건 미완료로 보류된다.

## 공개 스토어 확인 — 반영 대기

복구 직후 한국 공개 URL `https://apps.apple.com/kr/app/id6773636183`은
`찾으시는 페이지를 찾을 수 없습니다`를 표시했다. 가용성 설정 저장만으로 실제 다운로드·업데이트가
가능해졌다고 표시하지 않는다. Apple 화면은 변경 사항이 24시간 이내에 반영된다고 안내한다.

연결된 기기에는 이미 1.2.8 코드의 개발 서명 검사본이 있으므로 스토어의 `열기`만으로
구버전에서의 업데이트 설치를 증명할 수 없다. 검증을 위해 앱 삭제·구버전 덮어쓰기·데이터 초기화를
하지 않는다. 공개 페이지의 최신 버전·다운로드 가용성, 실제 Store 설치, 구버전 업데이트 검증은
각각 별도 증빙으로 기록한다.

현재 전체 푸시 발송은 0건이며 스토어 실제 반영·업데이트 연결 확인 전에 보내지 않는다.
